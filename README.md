### About

I build machine learning systems that do the reasoning people currently do by hand.

- 5+ years shipping production ML and generative AI — now building autonomous agents for scientific research.
- At **Aziro Technologies** (client: **Dr. Reddy's Laboratories**): an agent that navigates chemical space to surface novel molecule candidates, plus in-house small language models trained for chemical reaction prediction.
- Day-to-day: agentic orchestration with CrewAI, model fine-tuning, RAG over scientific literature, computer vision, and end-to-end delivery on Flask/Streamlit, Ray and Azure.
- Interested in agent architectures, AI for drug discovery, small language models, and applied NLP evaluation.

### What I'm building

| Project | What it is |
| --- | --- |
| **Bio Drug Discovery Agent** *(private, @ Aziro Technologies · Dr. Reddy's Laboratories)* | An autonomous agent for pharmaceutical R&D that explores chemical space to identify new molecule candidates, backed by purpose-trained SLMs for reaction prediction. Combines agentic reasoning, scientific-literature retrieval and in-house fine-tuned models to shorten the path from hypothesis to viable drug candidate. |
| **Chemical Reaction SLMs** *(private)* | In-house small language models fine-tuned for reaction prediction, cutting reliance on external LLM APIs. Validated through evaluation loops with domain chemists before release. |
| **Medical Chatbot on CrewAI** *(private, @ MSys Technologies)* | Internal multi-agent medical assistant on the CrewAI framework with a Streamlit interface, rolled out company-wide. |
| **Distributed RAG Retrieval** *(private, @ MSys Technologies)* | Scalable document-retrieval system using Ray.io for distributed parallel processing, with OpenAI models for augmentation. |
| **Vision OCR Extraction** *(private, @ MSys Technologies)* | Supervised fine-tuning of Phi Vision 3.5 for text extraction, lifting accuracy across mixed PDF and image inputs. |
| **Rental Verification Pipeline** *(private, @ MSys Technologies)* | Automated rental-application checks combining BERT review classification, Google Maps street-view imagery and Flask, with modules that auto-approve or reject applications. |
